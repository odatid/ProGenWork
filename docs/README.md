# ProGen GamePlan 公開版

このフォルダの内容を、GitHubリポジトリの `docs` フォルダとして配置する。

## 公開ファイル

- `index.html` — ProGen GamePlan 実行版
- `tools/ProGen_3Dモデル検証ラボ.html` — 3Dモデル検証ラボ
- `assets/kenney/` — Kenney CC0から選抜した44点の低ポリGLBモデル
- `assets/kenney/manifest.json` — 素材名・収録パック・公式配布元の台帳

Googleスプレッドシートを正本DBとして読み込む。3Dモデル検証ラボは、このリポジトリの `assets/kenney/` を参照する。モデルURLは、GitHub Pages上で表示を確認したものだけをシートの `10_素材セットDB` に登録する。
