このツールでやること

好きなゲームから「遊びの10軸」を見つけ、語れるネタで少し尖らせ、制作経験に合わせて現実的な企画候補を出します。

1. 好きな遊び
ゲームTOP3＋1位の好きポイントから主軸・副軸を判定
2. 語れるネタ
150ネタから最大5つ。登録ネタは嗜好を弱く補正
3. 作り方
Webで試す／今のUnityで作る／少し背伸び、から選ぶ

好きなゲームを3本まで選ぶ

順位を考えながら探す必要はありません。まず「好き」と思うゲームを最大3本選び、そのあと一番好きな1本だけ決めます。

選択中 0 / 3
一番好きなゲームの、何が特に好き？（最大2つ）
具体的な遊び方で選びます。括弧内は「遊びの10軸」です。

好き・語れるネタ

詳しい、好き、話せる、ゲームにしてみたいと思うものを最大5つ選んでください。

選択中 0 / 5
自由入力は企画には反映しますが、嗜好診断の10軸補正には使いません。

ゲーム制作経験

初めての人には細かい質問をしません。経験がある場合だけ少し確認します。

今回は何をしたい？

制作経験に応じて初期選択を変えます。いつでも変更できます。

あなたのゲーム嗜好

10軸全部を平均化せず、中心になる遊びを3つまで取り出します。

企画候補

「今の条件で安全」と「少し背伸び」の2系統を出します。

今の条件で作りやすい
少し勉強すれば作れそう

AI用プロンプト

このツール自体は生成AIのAPIを使いません。診断DBからプロンプトを作り、同じ生成AIチャットで順番に使います。

おすすめ手順： ①DB診断をもとに企画書を生成 → ②その企画書をもとにゲーム画面イメージ生成 → ③企画書と画面イメージをもとにWebプロト生成

1. ゲーム企画仕様概要書を生成

2. 直前の企画書からゲーム画面イメージを生成

3. 企画書＋ゲーム画面イメージからWebプロト生成
